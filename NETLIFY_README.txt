NETLIFY DEPLOYMENT
==================

This package is prepared for Netlify static hosting.

IMPORTANT:
- index.html is the main page.
- All site files are in the deployment root (not inside an extra folder).
- _redirects redirects the old /uchtepa_main.html URL to /index.html.

For Netlify:
1. Open your site in Netlify.
2. Deploy/upload this ZIP (or drag the unzipped folder).
3. The main page should open at your Netlify domain.
